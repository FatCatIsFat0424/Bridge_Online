# 99 規則（本站台式玩法）

> 採台灣最常見的玩法。2026-10-03。

## 基本

- 4 人，一副 52 張。
- 每人 5 張，其餘為牌堆。桌面累計點數從 0 開始。
- 第一位出牌者隨機決定，一開始為逆時針方向。

## 每一回合

1. 輪到的玩家打出 1 張牌，依下表改變累計點數或流程。
2. 打出後累計點數**不可超過 99**。
3. 從牌堆補 1 張，手牌維持 5 張。牌堆用完時，把已打出的牌（最上面那張除外）洗回牌堆。

## 牌的效果

| 牌 | 效果 |
| --- | --- |
| A | +1 |
| ♠A | 累計點數歸零 |
| 2、3、6、7、8、9 | 加上牌面點數 |
| 4 | 迴轉：出牌方向反轉，點數不變 |
| 5 | 指定：指定任一位仍在場的其他玩家為下一位，點數不變 |
| 10 | +10 或 −10（自選；−10 時最低到 0） |
| J | PASS：點數不變，直接換下一位 |
| Q | +20 或 −20（自選；−20 時最低到 0） |
| K | 累計點數直接變成 99 |

## 淘汰與勝負

- 輪到時，若手上每一張牌打出後都會讓累計點數超過 99，該玩家「爆掉」被淘汰，手牌棄掉，不再參與。
- 被淘汰後由下一位（依目前方向）繼續，累計點數不變。
- 最後留在場上的玩家獲勝。依淘汰順序排名（最後淘汰者第 2 名，以此類推）。
