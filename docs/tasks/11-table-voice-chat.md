# 11 — 牌桌語音、靜音與拒聽

日期：2026-10-03。

## 驗收範圍

- [x] 同房間四人語音，主動加入後才取得麥克風。
- [x] 自己麥克風靜音與拒聽其他玩家，兩個開關獨立。
- [x] 等待房間與對局皆提供文字聊天。
- [x] 同房間跨頁保留通話；退出、斷線與登出釋放音訊。
- [x] 伺服器驗證 session、房間及目標 peer，禁止跨房間轉送。
- [x] 語音為暫時狀態，不增加 JSON 寫入；不改變原有遊戲 / 儲存行為。
- [x] 麥克風拒絕、音訊播放限制與連線錯誤可見且可重試。
- [x] HTTP / Socket、前端生命週期與實際 WebRTC 瀏覽器驗證。
- [x] TypeScript、ESLint、完整測試、正式建置及 Wiki 同步。

## 驗證結果

- `npm run typecheck`、`npm run lint`、`npm run build:client` 通過。
- `npm test`：188 個測試、20 個檔案全部通過；新增 9 個伺服器語音測試與 20 個前端生命週期 / ICE 設定測試。
- Edge headless、四個獨立瀏覽器 context 與測試帳號、瀏覽器模擬麥克風，使用實際 WebRTC 音訊傳輸。
- 四位玩家各自建立三條遠端連線，收到音訊 RTP 封包；確認靜音自己的音軌、拒聽所有遠端播放，且拒聽涵蓋後加入的玩家。
- 查看個人頁、返回房間與四人準備進入正式對局均持續通話；對局訊息送達四人。
- 390px 視窗文件寬度仍為 390px；離開語音或房間後音軌結束，其他玩家移除對應連線；無頁面 JavaScript 錯誤。
- 測試等待遊戲頁內容掛載後才操作聊天，避免把路由載入期間仍顯示的等待房間輸入框當成遊戲頁。

本機測試不涵蓋實體麥克風音質或不同 NAT / 防火牆；尚未配置 TURN 服務。

實作與部署說明見[牌桌語音](../wiki/voice-chat.md)。
